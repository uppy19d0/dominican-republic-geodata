# Security Policy

Thank you for helping keep `dominican-republic-geodata` safe and reliable.

## Supported Versions

Security fixes are prepared for the latest published minor version while the package is below 1.0.

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |

## Reporting a Vulnerability

Please do not open a public issue for a vulnerability. Report security concerns through GitHub private vulnerability reporting when available, or contact the maintainer from the npm package metadata.

Include:

- Package version and runtime environment.
- A minimal reproduction or affected export.
- Expected impact and whether the issue affects build tooling, package contents, or runtime consumers.

## Supply Chain

The package is zero-dependency at runtime. Releases are validated with type checking, tests, build verification, package export verification, and `npm pack --dry-run`.
